# আল-ইত্তিহাদ ৫২ — অ্যাপের খোলস
- শিক্ষার্থী অ্যাপ: `app/` (মূল লিংক `/` নিজে থেকে এখানে নিয়ে যায়)
- অ্যাডমিন অ্যাপ: `admin/` (`/admin.html` নিজে থেকে এখানে নিয়ে যায়)
দুটোর scope আর id আলাদা, তাই একই ফোনে দুটো আলাদা অ্যাপ হিসেবে ইনস্টল হয় (অ্যাডমিনের আইকন সোনালি)।
আসল কোড প্রাইভেট রিপোতে। `config.js`-এ শুধু Apps Script-এর /exec লিংক।
